# GeoSismosLatam V16.9 — Flete terrestre

Fórmula: `Costo total = Distancia vial (km) × Toneladas × S/ 6.55`.

Equivalente Excel: `=Distancia_km*Toneladas*6.55`.

El cálculo económico ya no usa combustible ni fuentes externas. La distancia se obtiene automáticamente entre los distritos seleccionados mediante el motor de rutas disponible.
