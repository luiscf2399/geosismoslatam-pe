# GeoSismosLatam V16.10 — Mercados
- Se elimina la búsqueda producto por producto.
- El usuario selecciona únicamente el mercado.
- Al seleccionar un mercado se carga automáticamente toda la lista disponible.
- Columnas: producto, precio diario, unidad, ingreso diario (t), mercado y fecha.
- Se elimina del bloque comercial el análisis/modelo de siembra.
- No se inventan precios ni toneladas: si la fuente no entrega un dato, se muestra —.
- Las referencias históricas existentes no se etiquetan como precios de hoy; se expone la fecha del reporte.
