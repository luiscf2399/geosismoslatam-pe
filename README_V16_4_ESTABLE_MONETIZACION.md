# GeoSismosLatam V16.4 ESTABLE

Incluye asistente contextual permanente a la derecha en escritorio, panel IA móvil, espacios publicitarios pequeños y claramente identificados, portal Servicios CLIF, mejora del módulo Construcción/Suelos y consolidación visual.

## Publicidad
Los recuadros PUBLICIDAD son placeholders. No contienen un ID AdSense inventado. Cuando AdSense apruebe el sitio, configurar bloques reales respetando que no cubran mapas, alertas, GPS ni controles críticos. Para Android usar AdMob.

## IA
Las guías rápidas funcionan localmente. `/api/assistant` queda como punto de integración para un proveedor IA; hasta configurarlo, las preguntas abiertas muestran un aviso de servicio no configurado.

## Seguridad informativa
Mantener etiquetas OFICIAL, CONTRASTADO, EXPERIMENTAL y POR VERIFICAR. La IA no debe fabricar valores ausentes.
