# GeoSismosLatam V6.1 — ficha de evento + fuentes oficiales

Mejoras:
- Nueva ficha amplia del evento seleccionado inspirada en la claridad informativa de IGP, con diseño propio.
- Datos: referencia, hora Perú, coordenadas, profundidad, intensidad y magnitud.
- Accesos a IGP/CENSIS y contraste USGS cuando corresponda.
- Rangos visuales M<4.5, M4.5–5.9 y M>=6.0.
- El rango correspondiente al evento seleccionado se destaca automáticamente.
- Barra permanente de fuentes oficiales y agradecimiento.
- Declaración explícita de independencia para no sugerir afiliación o respaldo estatal.
- La ficha se actualiza al pulsar un epicentro o un elemento de la lista.

Para publicar, reemplaza:
index.html
app.js
styles.css
sw.js

Si ya estás en V6 robusta, no necesitas volver a sustituir worker.js o wrangler.jsonc para esta mejora visual.
