# GeoSismosLatam V16.6 — Autocompletado global

Se añade autocompletado automático para campos de búsqueda de productos, mercados, temas y ubicaciones. Los campos territoriales usan la base UBIGEO incluida; los campos agrícolas incluyen una lista amplia de productos y mercados. Los buscadores de ruta que ya usan POI/autocompletado remoto conservan su sistema especializado. Los campos creados dinámicamente, como paradas intermedias, también reciben sugerencias automáticamente.

Objetivo: evitar búsquedas vacías o ambiguas y permitir seleccionar una opción válida antes de consultar.
