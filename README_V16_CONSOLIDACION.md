# GeoSismosLatam V16 – Consolidación

V16 consolida el portal antes de seguir agregando módulos.

## Cambios
- Centro de Situación integrado y acceso rápido a sismos, lluvias, carreteras, riesgos, mercados y mar.
- Indicador de disponibilidad/calidad de fuentes.
- Diferenciación visual OFICIAL / EXPERIMENTAL / COMUNITARIO.
- Mapas más compactos, leyendas arriba y navegación horizontal móvil.
- Botones por visor: actualizar, pantalla completa y favoritos.
- Detección de conexión y uso de caché existente.
- Actualización progresiva para evitar bloquear toda la interfaz.
- Mantiene V15: GPS, rutas, mercados, calculadora experimental de fletes, radar agrario público, mar/pesca y lluvias.

## Criterio de datos
Nunca presentar estimaciones experimentales como alertas oficiales. IMERG se usa como observación satelital; pronósticos y escenarios se identifican por horizonte y fuente.
