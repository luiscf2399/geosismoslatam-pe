# GeoSismosLatam V16.11 — Último precio disponible

- Al seleccionar un mercado se mantiene la lista completa.
- Si un producto tiene dato en el último reporte cargado: `ACTUALIZADO`.
- Si no tiene dato reciente: se muestra el último precio disponible conocido para ese producto.
- La fecha real del dato se conserva siempre.
- No se interpola, proyecta ni inventa ningún precio.
- La tabla incluye una nueva columna `Estado`.
