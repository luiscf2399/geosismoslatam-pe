# GeoSismosLatam Web V12

## Leyenda contextual por situación visual
La leyenda ya no es genérica. Cambia por visor, capa, variable, horizonte y selección.

Secuencia de contexto:
- Visor activo
- Capa activa
- Variable representada
- Unidad o categoría
- Horizonte temporal
- Elemento seleccionado

Visores cubiertos: sismos, proyección sísmica, lluvias, riesgos, suelos, agricultura y mar/pesca.
La simbología oficial de cada entidad prevalece sobre cualquier guía auxiliar del portal.
