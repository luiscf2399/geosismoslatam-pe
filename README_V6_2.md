# GeoSismosLatam V6.2 — Meteorología, Mar y Pesca

## LLUVIAS
- Imagen satelital NOAA GOES para Sudamérica sur (actualización desde el backend).
- Enlace oficial NASA GPM / IMERG para estimación satelital de precipitación.
- Pronóstico estacional SENAMHI.
- Pronóstico numérico SENAMHI mediante WMS.
- Aviso 24 h de lluvias intensas SENAMHI.
- Activación de quebradas SENAMHI.
- Pronóstico DHN de viento sobre el mar peruano.

## MAR Y PESCA
- Nueva pestaña independiente.
- Puertos/sectores costeros referenciales asociados a la tabla de mareas DHN.
- Acceso a pleamares/bajamares DHN.
- Panel explicativo sobre Línea de Más Alta Marea (LAM).
- NO se inventa una LAM cartográfica donde no existe una capa pública oficial interoperable.
- Pronóstico DHN de viento/estado del mar.
- Pesca recreativa responsable: vedas, tallas mínimas, especies protegidas y captura/liberación.
- Sectores costeros para PLANIFICAR una salida, no como zonas oficialmente habilitadas de pesca.
